# apps

Small web apps, served by GitHub Pages at https://josephwroot.github.io/apps/

- `clef-climb/` — Clef Climb, a note-reading game. Installable on a phone from Safari with Share → Add to Home Screen; works offline once installed.
- `papers/` — Papers, review notes on major papers by topic, with a quiz mode that hides each note until tapped. Content is in `papers/papers.md`. Installable the same way; works offline once installed.
